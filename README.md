# Ember & Oak Coffee House

A static one-page site for a cozy downtown coffee shop. Warm tones, mobile-first.

## Structure

- `index.html` — markup: hero, menu, hours, contact, footer
- `style.css` — warm cream/oak/ember palette, responsive layout
- `script.js` — auto-updates the year and highlights today in the hours list

## Sections

1. **Hero** — name (Ember & Oak), tagline ("Slow mornings. Strong coffee. Good company.")
2. **Menu Highlights** — six signature drinks & a bakery item, with prices and tags
3. **Hours** — full weekly schedule; today's row is auto-highlighted
4. **Visit / Contact** — address, phone, email, socials

## Notes

- Pure static, no build step. Open `index.html` directly to preview.
- Fonts loaded from Google Fonts (Fraunces + Inter).
